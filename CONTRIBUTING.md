# Contributing to MissingMedicines AI 🤝

Thank you for your interest in contributing to MissingMedicines AI.

Our goal is to improve healthcare accessibility by helping citizens track medicine availability in government hospitals through crowdsourced reporting and AI-powered insights.

---

## Ways to Contribute

You can contribute in several ways:

### 🐛 Report Bugs

If you find a bug, please create an issue and include:

* Clear description of the problem
* Steps to reproduce the issue
* Expected behavior
* Actual behavior
* Screenshots (if applicable)

---

### ✨ Suggest Features

We welcome ideas that improve:

* Medicine availability tracking
* Hospital recommendation systems
* AI-powered shortage prediction
* User experience and accessibility
* Dashboard analytics

---

### 📝 Improve Documentation

Help improve:

* README.md
* CONTRIBUTING.md
* USER_MANUAL.md
* Code comments
* Installation instructions

---

### 💻 Submit Code Contributions

Contributors can help with:

* Streamlit UI development
* Database management
* Groq API integration
* OpenStreetMap integration
* Data visualization
* Testing and debugging

## Getting Started

### Prerequisites

* Python 3.8+
* Git
* GitHub Account
* Groq API Key (for AI features)

---

### Clone the Repository

```bash
git clone https://github.com/akhilavishwanath/MissingMedicines-AI.git
cd MissingMedicines-AI
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```

---

## Development Workflow

### Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

Example:

```bash
git checkout -b feature/dashboard-improvement
```

### Commit Changes

```bash
git add .
git commit -m "Add dashboard improvements"
```

### Push Changes

```bash
git push origin feature/your-feature-name
```

### Create Pull Request

Submit a Pull Request describing:

* Changes made
* Purpose of the changes
* Screenshots (if applicable)
